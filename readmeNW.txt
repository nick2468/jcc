To compile a C file

jcc.bat "C:\Users\nick2\Code\HelloWorld\HelloWorld.c"

  Or with an explicit output name:

  jcc.bat "C:\Users\nick2\Code\HelloWorld\HelloWorld.c" -o "C:\Users\nick2\Code\HelloWorld\HelloWorld.exe"

git add .
